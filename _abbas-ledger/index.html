Checking the connection…

Not connected yet. Three things to do once, then this all works by itself.

  1. In MYP go to CRM → Administration → API applications and register an application called Payments Ledger. Copy the Client ID and Client Secret — the secret only shows once. (If that menu isn’t there, your MYP Champion needs to turn on API permissions for you.)
  2. In Netlify open abbas-ledger → Site configuration → Environment variables and paste them into MYP_CLIENT_ID and MYP_CLIENT_SECRET.
  3. Come back here, tap Check again.
