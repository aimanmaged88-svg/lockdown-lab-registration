# UNC LIVE decks

The four session decks are built by these scripts, so they can be rebuilt from
scratch if the files are ever lost.

- `gen234.js` — Session 1 Mindset, Session 2 Defence, Session 3 Nutrition
- `gen.js` — Session 4 Basketball IQ

Both need `pptxgenjs` and the logo:

    npm i pptxgenjs
    node gen234.js
    node gen.js

Session order was set by Aiman: Mindset → Defence → Nutrition → Basketball IQ.
Each is $10 a seat, 20 seats, run over Zoom.
