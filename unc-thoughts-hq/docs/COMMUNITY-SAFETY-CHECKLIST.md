# Community safety checklist

**Read and complete this before enabling Release B (the adult community beta).**
The flag is off by default for a reason.

## Non-negotiable defaults (built in)

- [x] Community is **adults 18+ only**. Signup requires an 18+ confirmation and
      records consent.
- [x] **No private adult-to-child messaging** exists anywhere in the product.
- [x] Reporting, blocking (status), muting, moderation queue, moderator notes,
      audit trail, escalation via the inbox.
- [x] Slow mode, lockable discussions, read-only announcement spaces.
- [x] Restricted-word filter + basic rate limiting / anti-spam on posts.
- [x] Transparent enforcement reasons recorded on every moderation action.
- [x] Consent records (18+, guidelines, recording appearance, data processing).
- [x] Account deletion, content deletion, and data export workflows.
- [x] Nutrition language linter (general education only).

## Before you turn it on

- [ ] A named **safeguarding lead** / responsible adult is identified.
- [ ] Community guidelines (`COMMUNITY-GUIDELINES.md`) are published to members.
- [ ] A **privacy policy** reviewed by a solicitor is live (see `PRIVACY.md`).
- [ ] `AUTH_SECRET` is set to a long random value in `.env`.
- [ ] You have a plan to action reports within a stated time.
- [ ] You have confirmed you will keep the community adults-only.

## If youth participation is ever considered (later — do NOT rush this)

Youth accounts must **not** be enabled until ALL of the following are in place:

- [ ] Legal review (Australian law).
- [ ] Privacy Impact Assessment.
- [ ] Safeguarding lead + trained moderation.
- [ ] Appropriate **age assurance**.
- [ ] Guardian involvement/consent where required.
- [ ] **Two-deep** adult communication (never 1:1 adult–child).
- [ ] Safe defaults, data minimisation, location protection.
- [ ] Image/video consent workflow for minors.
- [ ] Clear incident escalation + regular safety audits.
- [ ] Alignment with the **National Principles for Child Safe Organisations**
      and **eSafety** guidance (both seeded in the Research Library).

Until then: serve younger players through **public educational content, parents,
guardians and coaches** — not accounts.
