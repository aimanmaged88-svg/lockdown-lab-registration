# SiteFive — Brand guide

Keep everything consistent and it looks like a real, established company. One page, everything you need.

## Name & tagline
- **Name:** SiteFive (one word, capital S, capital F)
- **Tagline:** *Websites for local business. Live in 5 days.*
- **One-liner:** Simple, beautiful websites for local Sydney businesses — live in 5 days, or it's free.

## Logo files (in this `brand/` folder)
| File | Use it for |
|------|-----------|
| `logo-mark.svg` | The "5" icon on its own (app icons, avatars) |
| `logo-full.svg` | Icon + "SiteFive" wordmark (vector, scales forever) |
| `logo-wordmark-dark.png` | Wordmark on dark backgrounds |
| `logo-wordmark-light.png` | Wordmark on white/light backgrounds |
| `icon-512.png` / `icon-192.png` | App / PWA icons |
| `apple-touch-icon.png` | iPhone home-screen icon |
| `favicon.svg` / `favicon-32.png` | Browser tab icon |
| `ig-profile.png` | **Instagram / Facebook profile picture** |
| `og-image.png` | The preview image when your link is shared (already wired into the site) |

**Logo rules:** keep clear space around it, never stretch it, never recolour the gradient. On busy photos, use the wordmark version with a solid background behind it.

## Colours
| Role | Hex |
|------|-----|
| Ink / near-black (dark bg) | `#0b0d12` |
| Text on light | `#0c111c` |
| Muted text | `#4c5666` |
| Accent gradient | `#4ade80` → `#22d3ee` (green → cyan, 135°) |
| Accent (solid, for print/text) | `#0F9D66` |
| Accent ink (text on the gradient) | `#04140a` |

The gradient is the signature. Use it for the logo tile, buttons and highlights — not for large blocks of text.

## Type
System sans everywhere (`-apple-system, "Segoe UI", Roboto, Helvetica, Arial`). Headlines heavy (800–900) and tight; body regular. No fancy fonts — clean and fast is the look.

## Voice & tone
- **Plain English, no jargon.** Talk like a helpful local, not an agency.
- **Confident and warm.** Short sentences. Benefits, not features ("jobs straight to your phone", not "click-to-call functionality").
- **Honest.** No fake numbers, no overpromising. The guarantees are real — keep them.
- Emoji are fine in social and friendly emails, sparingly. Keep invoices/proposals clean.
